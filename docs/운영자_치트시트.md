# 사유의 방 · 운영자(강사) 치트시트

> 강의 운영에 필요한 URL·장치·규칙 총정리 — 한 장. (수강생에겐 공유하지 않는 문서)

---

## 1. 접속 URL 형식

기본 접속: `https://<배포주소>/` (로컬은 `http://localhost:8000/`)

| 목적 | URL |
|------|-----|
| 인트로(첫 화면) | `/` 또는 `/#/` |
| 입장 화면 바로 | `/#/start` |
| 사유의 방(상자 4개) | `/#/room` |
| 특정 상자 카드 펼침 | `/#/box/0` ~ `/#/box/3` (0=왜 1=도구 2=적용 3=지속) |
| 특정 강의 바로 | `/#/lecture/7` (이어보기 위치에서 시작) |
| 특정 슬라이드 바로 | `/#/lecture/7/5` (7강 6번째 슬라이드 — 0부터 셈) |
| 진단실 | `/#/practice` |

## 2. 강사 운영 스위치 (쿼리 파라미터)

| 스위치 | 효과 | 쓰는 순간 |
|--------|------|----------|
| `?variant=personal` | 7·8강을 **경험판**(한방자료·NanoClaw 개인 스토리, 14/16장)으로. HUD에 작은 "P" 뱃지 | 강사 본인이 직접 강의할 때. **평소 배포 링크엔 붙이지 않는다**(기본=범용판) |
| `?unlock=1` | **진단실 전층 해금** (Lv·이전층 조건 무시) | 강의 중 진단실 시연 |
| `?view=pc` / `?view=mobile` | 기기 판정 강제 (PC=Lv 스킨 잠금 있음 / 모바일=스킨 전부 해금·배경 정적) | 한 기기에서 두 모드 확인 |
| `?join=반이름` | 입장 화면의 **⚙️ 설정 레이어를 자동으로 열고**, 수강 코드 입력란에 `반이름-`을 미리 채운다. 수강생은 번호만 입력하면 됨(예: `07` → `A반-07`). 저장하면 레이어가 자동으로 닫히고 바로 [강의실 입장] 가능. **이미 코드가 저장돼 있으면 무시**(재입력 강요 없음) | QR·단체 링크로 배포할 때 |
| 조합 예 | `/?variant=personal&unlock=1#/practice` | 경험판 + 진단실 시연 |
| 조합 예 | `/?join=A반#/start` | A반용 QR 코드에 넣는 링크 |

## 3. 초기화 (강의 시작 전 준비)

- **전체 초기화**: `/#/reset` 접속 → Lv1·진행도 0·이어보기 삭제 후 인트로로.
- 부분 초기화: 방 화면 우상단 **↺** (진행도만 리셋 — Lv·스킨은 유지).
- 주의: 데이터는 각 브라우저(localStorage)에 저장 — **시연 PC에서 초기화해도 수강생 폰에는 영향 없음** (반대도 마찬가지).

## 4. Lv · 스킨 해금 규칙 (게이미피케이션)

- **완료 판정**: 강의를 *마지막 슬라이드까지* 봐야 그 강이 완료(상자 점 켜짐).
- **완주**: 20강 전부 완료 → 축하 연출 → **⬆ 업그레이드** 클릭 → Lv+1 & 진행도 리셋(= 새 회독).
- **Lv 상한 3**(개정: `order/게이미피케이션_Lv3_지시서.md` ②, `js/site-config.js`의 `maxLevel`로 조정).
- **Lv 칭호**: Lv1 Wanderer → Lv2 Thinker → Lv3 Visionary(✦통달).
- **스킨 해금(PC)**: Lv1 사유의 방·픽셀 → Lv2 +네온 → Lv3 +블루프린트. 페이퍼는 이 사이트에서 제외
  (첫걸음 전용, 코드는 유지). 잠긴 스킨엔 "LvN" 뱃지 표시. **모바일은 처음부터 4종 전부 해금.**
  해금 Lv은 `js/site-config.js`의 `skinUnlockLevel`로 스킨별 조정(엔진 하드코딩 없음).

## 5. 진단실 층 해금 조건

| 층 | 조건 |
|----|------|
| 검사실 (검사 3종) | 항상 개방 |
| 1층 AI 손에 익히기 | **Lv2 달성** (= 20강 1회 완주 후 업그레이드) |
| 2층 내 일 진단하기 | 1층 4개 전부 완료 |
| 3층 조직 진단·제안서 | 2층 4개 전부 완료 |

- **입장 화면 노출**: Lv2 미만은 입장 화면에 진단실 버튼 자체가 없다(완전 미노출). Lv2에 처음 도달하는 순간 은은한 등장 연출 + "진단실이 열렸습니다" 토스트가 1회 뜨고, 이후엔 조용히 표시된다. `?unlock=1`이면 Lv 무관하게 상시 노출.
- 시연 때는 `?unlock=1`로 전층 개방. 제안서(3-4)는 📋복사·🖨️인쇄 지원.
- 진단실 데이터는 별도 키(axp_*) — 강의 진행도 초기화(↺)와 무관하게 유지. `#/reset`도 진단실 산출물은 지우지 않음.

## 8. 수강 코드 · 학습 현황 수집 (LMS 1단계)

- **코드는 선택**이다 — 입장 화면에서 코드를 입력한 사람만 학습 현황이 서버로 전송된다.
  코드 없이 쓰면 지금까지와 100% 동일(수집 없음, 완전 개인 사용).
- **발급 규칙 제안**: `반이름-번호` 형식(예: `A반-07`, `오후반-13`). 짧고 구분 가능하면 무엇이든 가능(2~20자).
- **수집되는 이벤트 6종**

  | event_type | 시점 | payload |
  |---|---|---|
  | `session_start` | 코드 등록/재방문 시 세션당 1회 | skin, viewMode |
  | `lecture_complete` | 강의 마지막 슬라이드 도달 | lectureId, level |
  | `run_complete` | 20강 완주 후 업그레이드 클릭 | newLevel |
  | `diagnosis_result` | 진단실 검사 3종 각 완료 시 | kind(literacy/native/tacit), scores |
  | `checkup_result` | 조직 건강검진(3-1) 저장 시(재검사도 매번) | scores(방향·데이터·사람·규칙·분위기), lowest |
  | `proposal_created` | 제안서(3-4) 최초 완성 | hasAll(12스테이션 전부 완료 여부) |

- **데이터를 눈으로 보는 법 ① — 원본**: Supabase 대시보드 → 좌측 **Table Editor** → `events` 테이블.
  최신순 정렬, `code`로 필터하면 특정 수강생만 볼 수 있다.
- **데이터를 눈으로 보는 법 ② — 대시보드**: 아래 9번 참고(`#/admin`, LMS 2단계).
- **끄는 법**
  - 수강생 단위: 코드를 입력하지 않고 쓰면 애초에 수집 없음.
  - 강사가 이미 등록된 코드를 지우고 싶을 때: 입장 화면 **⚙️ 설정 → 수강 코드**의 **제거** 버튼, 또는 `#/reset`(코드도 함께 초기화).
  - 전체 중단: Netlify 환경변수에서 `SUPABASE_URL` / `SUPABASE_SERVICE_KEY`를 제거·비우면 서버 함수가 즉시 저장을 멈춘다.
    (프론트는 fail-silent라 이 상태에서도 학습 화면은 완전히 정상 동작한다.)

## 9. 강사 대시보드 (`#/admin`, LMS 2단계)

- **접근**: 주소창에 직접 `/#/admin` 입력(입장 화면·설정 레이어 어디에도 진입 버튼이 없다 — 수강생 화면 오염 방지).
  처음 들어가면 **접속 키 입력** 화면 → 맞으면 대시보드, 틀리면 "키가 올바르지 않습니다".
- **접속 키**: `.env`(로컬)와 Netlify 환경변수의 `ADMIN_KEY` 값. **수강생에게 절대 공유하지 않는다.**
  키가 바뀌면 기존에 로그인했던 브라우저도 다음 요청부터 재입력을 요구한다.
- **세션**: sessionStorage에 저장 — 새로고침·재방문에도 유지되지만 **브라우저(탭)를 닫으면 만료**된다.
  다른 강사 PC에서 접속했다면 특히 확인 필요(공용 PC라면 사용 후 탭을 닫아 키를 지울 것).
- **화면 구성**
  - 요약 헤더: 수강생 수·평균 완주율·오늘 활동 수강생 수, **과정 필터**(여러 사이트가 같은 Supabase를
    공유할 때 대비 — 값은 데이터에서 자동 추출, 지금은 `ax` 하나뿐이라 평소엔 "전체 과정" 그대로 두면 됨) +
    반 필터(코드 접두어로 자동 추출, 과정 필터와 함께 좁힐 수 있음), 새로고침.
  - 진행 매트릭스: 수강생 × 1~20강 완료 현황. 행 끝에 완료 수·Lv·최근 활동. **⚠ = 7일 이상 미접속**.
    열 머리에 강의별 완료 인원 미니 바(어느 강에서 이탈이 많은지 한눈에). 20개 강의 열은 좌우 스크롤.
  - 진단 집계: 리터러시 4축 팀 평균(레이더)+최약축, 네이티브 지수 평균+유형 분포, 암묵지 위험도 평균+판정 분포,
    조직 건강검진 5축 팀 평균(레이더)+가장 짧은 다리. 응답자가 아직 없는 항목만 "데이터 없음"으로 표시.
  - 행 클릭 → 그 수강생의 상세(완료 목록·Lv·진단 3종 결과) 레이어.
- **조회 전용** — 이 화면에서 데이터를 고치거나 삭제할 수 없다. 수정은 Supabase Table Editor에서.
- **끄는 법**: 원본 이벤트 수집을 끄면(8번 항목) 대시보드에는 새 데이터가 더 안 쌓일 뿐 화면 자체는 계속 동작(빈 상태).
  대시보드 접근 자체를 막으려면 Netlify 환경변수에서 `ADMIN_KEY`를 지운다(모든 키 입력이 401).

## 10. AI 주간 브리핑 (LMS 3단계)

- **위치**: 대시보드(`#/admin`) 요약 헤더 옆 **[📋 주간 브리핑]** 버튼.
- **하는 일**: 지금 보이는 집계(과정·반 필터가 걸려 있으면 그 범위만)를 Gemini에게 보내 강사 언어로
  5개 섹션 요약을 받아온다 — 이번 주 요약 · ⚠ 개입 필요 · 팀 진단 해석 · 콘텐츠 신호 · 다음 주 한 가지.
  레이어 제목에 현재 필터가 표기된다(예: "ax · A반 주간 브리핑").
- **화면에 표시·복사까지만** — 이 기능은 무엇도 자동으로 발송하거나 실행하지 않는다(17강 원칙).
  메일이나 메신저로 보내고 싶으면 **[📋 복사]**로 텍스트를 복사해 강사가 직접 붙여넣는다.
- **다시 생성**: 레이어 하단 **[↻ 다시 생성]** — 같은 데이터라도 매번 새로 호출한다(캐시 없음).
- **정확성**: 프롬프트에 "데이터에 있는 사실만 말하라"는 원칙이 박혀 있고, 수강생이 0명이면 AI를
  아예 부르지 않고 "데이터가 없습니다"로 즉시 응답한다(가짜 수강생을 지어내는 환각 원천 차단).
  그래도 브리핑은 **참고 자료** — 최종 판단은 매트릭스·진단 집계 원본을 강사가 직접 확인한다.
- **키**: `.env`(로컬)·Netlify 환경변수의 `AI_API_KEY`(Gemini). 없으면 브리핑 버튼을 눌러도
  "AI_API_KEY가 설정되지 않았습니다" 안내만 뜨고, 나머지 대시보드·수강생 화면은 평소대로 동작한다.
- **비용**: Gemini 무료 티어 기준(2026-07 확인) 분당 10회·일 500회 수준의 요청 한도.
  서버에서 분당 5회로 한 번 더 제한해두어 이 프로젝트 규모에선 사실상 무료 한도 안에서만 쓰인다.
  버튼은 강사만(ADMIN_KEY 인증 뒤) 누를 수 있어 남용 여지도 적다.
