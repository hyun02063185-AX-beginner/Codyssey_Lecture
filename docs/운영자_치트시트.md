# 사유의 방 · 운영자(강사) 치트시트

> 강의 운영에 필요한 URL·장치·규칙 총정리 — 한 장. (수강생에겐 공유하지 않는 문서)

---

## 1. 접속 URL 형식

기본 접속: `https://<배포주소>/` (로컬은 `http://localhost:8000/`)

| 목적 | URL |
|------|-----|
| 인트로(첫 화면) | `/` 또는 `/#/` |
| 입장 화면 바로 | `/#/start` |
| 사유의 방(상자 4개) | `/#/room` |
| 특정 상자 카드 펼침 | `/#/box/0` ~ `/#/box/3` (0=왜 1=도구 2=적용 3=지속) |
| 특정 강의 바로 | `/#/lecture/7` (이어보기 위치에서 시작) |
| 특정 슬라이드 바로 | `/#/lecture/7/5` (7강 6번째 슬라이드 — 0부터 셈) |
| 진단실 | `/#/practice` |

## 2. 강사 운영 스위치 (쿼리 파라미터)

| 스위치 | 효과 | 쓰는 순간 |
|--------|------|----------|
| `?variant=personal` | 7·8강을 **경험판**(한방자료·NanoClaw 개인 스토리, 14/16장)으로. HUD에 작은 "P" 뱃지 | 강사 본인이 직접 강의할 때. **평소 배포 링크엔 붙이지 않는다**(기본=범용판) |
| `?unlock=1` | **진단실 전층 해금** (Lv·이전층 조건 무시) | 강의 중 진단실 시연 |
| `?view=pc` / `?view=mobile` | 기기 판정 강제 (PC=Lv 스킨 잠금 있음 / 모바일=스킨 전부 해금·배경 정적) | 한 기기에서 두 모드 확인 |
| 조합 예 | `/?variant=personal&unlock=1#/practice` | 경험판 + 진단실 시연 |

## 3. 초기화 (강의 시작 전 준비)

- **전체 초기화**: `/#/reset` 접속 → Lv1·진행도 0·이어보기 삭제 후 인트로로.
- 부분 초기화: 방 화면 우상단 **↺** (진행도만 리셋 — Lv·스킨은 유지).
- 주의: 데이터는 각 브라우저(localStorage)에 저장 — **시연 PC에서 초기화해도 수강생 폰에는 영향 없음** (반대도 마찬가지).

## 4. Lv · 스킨 해금 규칙 (게이미피케이션)

- **완료 판정**: 강의를 *마지막 슬라이드까지* 봐야 그 강이 완료(상자 점 켜짐).
- **완주**: 20강 전부 완료 → 축하 연출 → **⬆ 업그레이드** 클릭 → Lv+1 & 진행도 리셋(= 새 회독).
- **Lv 칭호**: Lv1 Wanderer → Lv2 Explorer → Lv3 Thinker → Lv4 Practitioner → Lv5 Visionary(✦통달).
- **스킨 해금(PC)**: Lv1 사유의 방 → Lv2 +페이퍼 → Lv3 +네온 → Lv4 +픽셀 → Lv5 +블루프린트.
  잠긴 스킨엔 "LvN" 뱃지 표시. **모바일은 처음부터 5종 전부 해금.**

## 5. 진단실 층 해금 조건

| 층 | 조건 |
|----|------|
| 검사실 (검사 3종) | 항상 개방 |
| 1층 AI 손에 익히기 | **Lv2 달성** (= 20강 1회 완주 후 업그레이드) |
| 2층 내 일 진단하기 | 1층 4개 전부 완료 |
| 3층 조직 진단·제안서 | 2층 4개 전부 완료 |

- 시연 때는 `?unlock=1`로 전층 개방. 제안서(3-4)는 📋복사·🖨️인쇄 지원.
- 진단실 데이터는 별도 키(axp_*) — 강의 진행도 초기화(↺)와 무관하게 유지. `#/reset`도 진단실 산출물은 지우지 않음.

## 6. 슬라이드 조작 (시연 중)

| 조작 | 키/동작 |
|------|---------|
| 넘기기 | ← → · 스페이스 · 하단 버튼 · 모바일 스와이프 |
| 처음/끝 | Home / End |
| **도식 확대** | `+` 또는 이미지 클릭 → 전체화면 / `-`·Esc·클릭으로 닫기 |
| 나가기 | Esc (카드 목록으로) |
| **전체 목차** | 방 화면 우상단 **☰** → 20강 목록·이어보기·클릭 이동 |
| **핵심 훑기** | 목차 안 **⚡** 토글 → 각 강 핵심 문장만, 문장 클릭=해당 슬라이드 점프 |
| 전체화면 강의 | F11 (브라우저) |
