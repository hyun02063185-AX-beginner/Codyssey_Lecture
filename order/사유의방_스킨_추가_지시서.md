# CC 작업 지시서 — '사유의 방' 스킨 추가 (5번째)

> 위치: `Last_Lecture/order/사유의방_스킨_추가_지시서.md` · 경로는 모두 프로젝트 루트 기준.
> **전제**: `order/스킨_지시서.md`의 `data-skin` 스킨 시스템(paper·neon·pixel·blueprint)이 이미 적용돼 있어야 한다. 아직이면 그 지시서를 먼저 실행하고, 이 스킨을 5번째로 추가.

---

## 목표

국립중앙박물관 '사유의 방'을 모티브로 한 스킨을 **5번째 선택지**로 추가한다.

- `data-skin` 값: `sayu`
- 선택기 라벨: **사유의 방**
- 기본값은 그대로 `paper` 유지(사유의 방은 선택지로만 추가).
- 방침: 스킨은 일단 늘려두고 나중에 별로인 것을 뺀다 → 이번엔 **추가만**.

---

## 컨셉 (실제 전시관 근거)

'사유의 방'은 어둠이 내려앉은 고요한 명상 공간이다. 핵심 재료·빛:

- **적토(붉은 흙)벽** — 페인트 없이 손으로 바른 흙벽의 투박한 따스함.
- **남색 돔 천장** — 우주·시간의 영속성을 상징.
- **은은한 간접 조명** — 눈부시지 않고, 너무 어둡지도 않게.
- **아스라한 반짝임** — 별이 내리는 듯한 천장의 미세한 빛.

→ 번쩍이는 네온과 정반대의 **따뜻한 어둠 + 흙빛 + 별빛 골드** 스킨. 차분하고 명상적.

---

## 스킨 팔레트 (`:root[data-skin="sayu"]`)

> 변수명은 실제 `style.css` 스킨 블록의 이름에 맞춰 매핑. 상자 4색은 역할(①왜 ②도구 ③적용 ④지속) 유지하되, 이 스킨에선 흙·남색·별빛 계열로 톤을 통일한다.

```
--bg:            #0F0B09   /* 어둠 내려앉은 따뜻한 흑갈 */
--surface:       rgba(168,88,60,.08)    /* 적토 기운의 은은한 카드 (평면, 약한 온기) */
--surface-border:rgba(216,178,122,.22)  /* 별빛 골드 얇은 라인 */
--text:          #EDE4D6   /* 따뜻한 아이보리 */
--text-muted:    #A2937E   /* 흙빛 뮤트 */
--accent-1:      #D8B27A   /* 왜   : 별빛 골드 */
--accent-2:      #4A6FA5   /* 도구 : 천장 남색 */
--accent-3:      #B4664A   /* 적용 : 적토 테라코타 */
--accent-4:      #7E8B6D   /* 지속 : 고요한 세이지 */
--accent:        #D8B27A   /* 기본 인터랙션 = 별빛 골드 */
--glow:          0 0 30px rgba(216,178,122,.15)  /* 은은한 간접조명 (네온 아님) */
--radius:        18px      /* 타원형 전시대처럼 부드럽게 */
--shadow:        0 8px 30px rgba(0,0,0,.35)
--font-display:  'Nanum Myeongjo', serif   /* 명조 = 명상적/전시 느낌 */
--font-body:     'Pretendard', system-ui, sans-serif
```

**질감/분위기**
- 카드·표면은 backdrop-blur 대신 **평면 + 아주 옅은 흙빛 온기**. 테두리는 별빛 골드 얇은 선.
- 발광은 **은은한 따뜻한 헤일로**만(네온 금지).
- 선택적: 표면에 아주 옅은 흙 grain(노이즈) 오버레이 — 강하지 않게(투박한 흙벽 느낌).

**배경 캔버스(별/성운)를 sayu 인식하게**
- 차가운 성운을 끄고, **따뜻한 골드 별빛을 성기게** 뿌린다(별이 내리는 천장). 밀도 낮게, 아주 느리게, 은은하게.
- 색: `#D8B27A`~`#E8C98A` 계열, 낮은 투명도. 번쩍이지 않게.

## 폰트 추가

`index.html` `<head>`에 명조 폰트 로드(폴백 유지, 경로 틀리면 최신으로 교체):

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Nanum+Myeongjo:wght@400;700&display=swap">
```
(Pretendard는 스킨 시스템에서 이미 로드돼 있으면 재사용.)

## 선택기 UI

- 기존 스킨 선택기에 **다섯 번째 옵션 "사유의 방"** 추가(스와치 색: `#D8B27A` 위 `#0F0B09` 느낌).
- 클릭 시 즉시 반영 + `localStorage('axRoomSkin','sayu')` 저장. (기존 저장/전환 로직 재사용, 새 키 만들지 말 것.)
- 라벨 순서 예: `페이퍼 · 네온 · 픽셀 · 블루프린트 · 사유의 방`.
