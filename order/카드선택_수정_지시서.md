# CC 작업 지시서 — 사유의 방 카드 선택 UX 수정

> 위치: `Last_Lecture/order/카드선택_수정_지시서.md` · 경로는 모두 프로젝트 루트 기준.
> 이 작업은 **로컬 브라우저로 직접 보며 반복 검증**해야 한다(CC가 실행/스크린샷 가능).

---

## 증상

상자를 클릭해 카드가 부채꼴로 펼쳐질 때, **카드가 정신없이 움직여서 마우스로 고르기 어렵고, 클릭해도 슬라이드가 잘 안 열린다.**

## 목표

카드를 **크고, 안정적이고, 한 번에 클릭되게** 만든다. 구체적으로:
1. 펼침 애니메이션이 **한 번 재생 후 멈춰** 있을 것(가만히 있는 표적).
2. 마우스를 올렸을 때 카드가 커서 밖으로 도망가지 않을 것(호버 흔들림 제거).
3. 카드 클릭 → 해당 강의 슬라이드가 **첫 클릭에 확실히** 열릴 것.

---

## 작업 순서

1. **먼저 `js/room.js`와 `css/style.css`에서 카드 관련 코드를 읽고 원인을 진단한다.** 아래 "의심 원인"을 하나씩 대조.
2. 진단 결과에 따라 "수정 지침"을 적용(값은 실제 코드에 맞춰 조정).
3. **로컬 서버로 직접 확인하며 반복 검증**(아래 "검증 루프").
4. 카드/방 관련 외 파일(슬라이드 데이터, 다른 강의)은 건드리지 않는다.

---

## 의심 원인 (진단 체크리스트)

- [ ] 카드에 **무한 반복 애니메이션**(둥둥 뜨는 float/bob 등 `animation: … infinite`)이 걸려 있어 idle 상태에서도 계속 움직인다.
- [ ] 펼침 트랜지션이 **너무 빠르거나 튕김(elastic/overshoot)**이라 클릭 시점에 아직 정착 중이다.
- [ ] **호버 변형이 과도**(큰 scale/translate/rotate)해서, 카드가 커지며 커서 밖으로 빠져나가 → 호버 on/off가 반복(깜빡임 루프)된다.
- [ ] 부채꼴 **회전으로 카드 히트영역이 겹쳐** 이웃 카드가 클릭을 가로챈다(z-index 문제).
- [ ] **드래그/스와이프 핸들러**가 클릭과 경쟁해, 미세한 움직임이 클릭 대신 드래그로 처리된다.
- [ ] 클릭 핸들러가 카드 전체가 아니라 **작은 내부 요소**에만 걸려 있다.
- [ ] 카드 크기가 작아 애초에 표적이 작다.

---

## 수정 지침 (권장값 — 실제 코드에 맞춰 조정)

**1) 애니메이션을 "한 번만" 재생하고 멈춘다**
- 카드의 무한 반복 모션 제거(또는 아주 미세하게 하고 hover 시 `animation-play-state: paused`).
- 펼침 트랜지션: `transition: transform .32s cubic-bezier(.22,.61,.36,1)` 수준의 **ease-out, 튕김 없음**.
- 펼침이 끝나기 전에는 클릭이 빗나가지 않도록: 펼치는 동안 카드 `pointer-events:none` → 트랜지션 완료(`transitionend`) 후 `pointer-events:auto`. (또는 펼침을 충분히 짧게.)

**2) 호버를 안정화한다 (도망가지 않게)**
- 호버 변형을 작게: `transform: translateY(-8px) scale(1.03)` 정도, `transform-origin:center`.
- 호버된 카드는 `z-index` 최상단으로 올려 항상 위에서 온전히 클릭되게.
- 가능하면 호버 lift를 **래퍼(부모)** 에 적용해 히트영역 자체는 이동하지 않게 한다.

**3) 카드를 키우고 겹침을 줄인다**
- 카드 크기를 키우고(예: 폭 +15~20%), **부채꼴 각도/간격을 넓혀** 히트영역 겹침을 줄인다.
- 카드가 서로 겹쳐야 한다면, 각 카드에 충분한 `z-index` 순서를 주고 호버/포커스 시 최상단.

**4) 클릭 vs 드래그를 구분한다**
- 드래그 핸들러가 있으면 **이동 임계값**(예: 8px) 미만은 드래그로 보지 않고 클릭으로 처리.
- 클릭 핸들러는 **카드 루트 요소**(패딩 포함 전체)에 건다. 여는 동작이 `pointerup`/`click` 어디에 걸렸는지 확인.

**5) 접근성 겸 안정성**
- 카드에 `tabindex="0"`, `role="button"`, `Enter`/`Space`로도 열리게.
- `@media (prefers-reduced-motion: reduce)`에서 펼침을 즉시(모션 최소)로.

## 검증 루프 (로컬에서 직접 확인)

```bash
! python -m http.server 8000
# http://localhost:8000 → 입장 → 상자 클릭 → 카드 부채꼴
```

각 상자에서 확인:
- [ ] 카드가 **~0.4초 안에 펼쳐지고 그 뒤로 가만히** 있는다(계속 움직이지 않음).
- [ ] 각 카드에 마우스를 올리면 **살짝 떠오르되 커서를 놓치지 않는다**(깜빡임 없음).
- [ ] **5장 각각을 첫 클릭에** 열어본다 — 특히 겹치는 안쪽 카드도.
- [ ] 데모 강의(07·08) 카드도 정상적으로 슬라이드가 열린다.
- [ ] 빠르게 연타/가장자리 클릭에도 오작동 없음.
- [ ] 콘솔(F12) 에러 0건.

문제가 남으면 어떤 카드/상황에서 재현되는지 기록하고, 원인(호버 흔들림/겹침/드래그 오인 중 무엇인지)을 좁혀 재수정.

## 완료 체크리스트

- [ ] 무한 모션 제거, 펼침은 1회 재생 후 정착
- [ ] 호버 안정(도망/깜빡임 없음), 호버 카드 최상단
- [ ] 카드 크기↑·겹침↓, 5장 모두 첫 클릭에 열림
- [ ] 클릭/드래그 구분, 키보드로도 열림
- [ ] 콘솔 오류 0건, 방↔슬라이드 전환 정상
