# CC 작업 지시서 — 상자3 「적용」 강의 채우기 (11~15)

> 위치: `Last_Lecture/order/상자3_슬라이드_지시서.md` · 경로는 프로젝트 루트 기준.

---

## 목표

상자3 「적용」(accent `#f472b6`)의 **11·12·13·14·15강** slides를 채운다. 각 8장, 03강 톤.

| 강 | 제목 | 다음 강 티저 |
|----|------|------|
| 11 | 문서·보고서 자동화 | → 12 마케팅·콘텐츠 실무 |
| 12 | 마케팅·콘텐츠 실무 | → 13 데이터 정리와 분석 |
| 13 | 데이터 정리와 분석 | → 14 이메일·커뮤니케이션 자동화 |
| 14 | 이메일·커뮤니케이션 자동화 | → 15 업무 워크플로우 설계 |
| 15 | 업무 워크플로우 설계 | → 상자4 지속(16 자산 보호) |

## 작업 순서

1. `curriculum.md`·`js/data.js`에서 11~15강 위치·형식 확인.
2. 아래 slides를 각 강 객체에 삽입. 다른 강·css·엔진 미변경.
3. curriculum.md 해당 5강 목표/핵심메시지 갱신.
4. 필드명 실제 스키마 매핑(신규 필드 금지), accent `#f472b6` 유지.
5. 로컬 렌더 + 콘솔 오류 0건 확인.

타입: `cover`/`big`/`bullets`/`quote`/`split`/`closing`. `\n`=줄바꿈. `split` left/right 첫 항목=컬럼 제목.

## 개정 정의 (curriculum.md)

- **11 문서·보고서 자동화** — 목표: 백지 대신 AI 초안에서 시작해 다듬는 문서 작업법. 핵심: "초안은 AI, 결정은 나."
- **12 마케팅·콘텐츠 실무** — 목표: AI가 강한 영역(변주·실행)과 약한 영역(방향·발굴)을 구분해 활용. 핵심: "방향은 사람, 변주는 AI."
- **13 데이터 정리와 분석** — 목표: 자연어로 데이터 정리·분석하되 숫자는 반드시 검증. 핵심: "도구 실력에서 질문력으로."
- **14 이메일·커뮤니케이션 자동화** — 목표: 분류·요약·회신초안은 AI, 발송은 사람 확인. 핵심: "초안은 AI, 보내기는 사람."
- **15 업무 워크플로우 설계** — 목표: 낱개 도구를 하나의 흐름으로 엮고 사람 확인 지점을 설계. 핵심: "설계가 실력이다."
