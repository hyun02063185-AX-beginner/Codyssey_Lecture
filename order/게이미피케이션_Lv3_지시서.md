# CC 작업 지시서 — 진단실 버튼 정리 + 게이미피케이션 Lv3 개편 (양 사이트)

> 위치: `AX_Lecture/order/게이미피케이션_Lv3_지시서.md` · **AX_Lecture에서 시작, AI_First_Step까지 양쪽 작업.**
> 사용자 실사용 검토에서 나온 수정 요청. 권장 모델: 높음.
> 레벨 상한·스킨 게이팅은 **site-config 주도**로 구현(엔진 하드코딩 금지) — 엔진 변경분은 이식 대상으로 §7 기록.

## ① 입장 화면 — 진단실 버튼 다이어트 (AX)

- 진단실 입장 버튼에서 부제 텍스트 **`'3층 · 12단계 진단 · 우리 조직 AX 도입 킷'` 제거** — 버튼엔 `🧪 진단실 입장`만.
- 버튼 폭을 **[강의실 입장]보다 확실히 좁게**(시각 위계: 주 동선 > 부 동선). 중앙 정렬 유지.
- 5스킨·375px에서 확인.

## ② 레벨 체계 — 양 사이트 Lv 상한 3으로

**현행**: AX Lv1~5(완주 반복당 1레벨), 첫걸음도 칭호 5단계로 추정 — **먼저 양쪽 현행 구조(상한·칭호·보상 지점)를 확인해 보고**하고 아래로 개편.

- `SITE_CONFIG`에 `maxLevel: 3` (양쪽). 엔진은 이 값을 읽어 상한 처리 — 상한 도달 후 완주는 축하 연출만 하고 레벨은 유지.
- **칭호 3단계 재편**:
  - AX: 기존 5칭호에서 3개로 압축(1·중간·최종을 살리는 방향으로 CC가 선별, 결과 보고)
  - 첫걸음: 인턴 → 주임 → 에이스 (기존 5단계에서 압축 — 어색하면 조정 후 보고)
- **기존 localStorage 마이그레이션**: 저장된 Lv가 4·5인 사용자는 로드 시 **3으로 클램프**(진행 기록은 보존). 오류 없이 조용히.

## ③ 스킨 보상 재편

### AX_Lecture
| Lv | 해금 스킨 |
|---|---|
| 1 (시작) | **사유의 방 · 픽셀** |
| 2 | 네온 |
| 3 | 블루프린트 |

- **페이퍼 스킨은 AX에서 제외** — availableSkins에서 제거. 스킨 코드 자체는 삭제하지 말 것(첫걸음이 사용).
- **기본 스킨 = 사유의 방**으로 변경(defaultSkin — 페이퍼가 빠지므로. 다크 몰입형 첫인상은 사이트 정체성에 부합, 의도된 결정).
- **마이그레이션**: 저장된 스킨이 'paper'인 사용자는 로드 시 사유의 방으로 폴백(오류 없이).

### AI_First_Step
| Lv | 해금 스킨 |
|---|---|
| 1 (시작) | **오피스 · 페이퍼** |
| 2 | 네온 |
| 3 | **노을 (신규)** |

- 기존 "게이팅 없음" 정책을 **게이팅 적용**으로 변경(사용자 결정).
- **신규 스킨 `sunset`(노을)** 제작 — 콘셉트: *"첫 출근을 마치고 퇴근길에 보는 노을"*. 최고 레벨 보상다운 감성 스킨:

```
--bg: 어스름 남색~보라 (#2B2140 계열) · --surface: 반투명 어두운 카드
--accent: 노을 앰버 #F59E0B ~ 코럴 #F97316 그라데 포인트 (과하지 않게)
--text: 따뜻한 미색 #F5EFE6 · muted: #A99BB5
질감: 배경 하단에 은은한 노을 그라데이션(정적), 별 한두 점 허용. fxLevel calm과 어울리게 절제.
office(아침)→노을(저녁)의 하루 서사가 느껴지도록.
```

- 스킨 선택기(🎨)에 잠금 Lv 뱃지 표시(양쪽 규칙 통일).
