# 「사유의 방」 서비스 현황 브리핑 — 기획 논의용

> 이 문서는 클로드(채팅)와 서비스 기획을 이어가기 위한 현황 요약이다.
> 페이지를 직접 볼 수 없는 상대에게 서비스 전체를 전달하는 것이 목적.
> 기준일 2026-07-18 · 저장소 main 최신 기준 · 수치는 전부 실측값(전체 점검 보고서에서 발췌).

---

## 1. 한 줄 소개

**「사유의 방」** — 사내 비개발 직군(마케팅·기획·운영)을 위한 **AX(AI 전환) 입문 20강 인터랙티브 강의 웹**.
다크·별빛 감성의 "방"을 탐험하며 강의를 발견하는 게이미피케이션 구조. 강사가 데모데이(20분) 시연 + 이후 수강생 자율 반복학습을 겨냥.

- 형태: **빌드 없는 정적 웹**(HTML/CSS/JS, 서버·DB 없음) · GitHub 저장소 · 로컬/정적 호스팅으로 서빙
- 제작 방식: 강사(기획·콘텐츠) + Claude Code(구현) 바이브 코딩
- 현 수준 평가: **"실사용 v1 직전의 고급 데모"** (전 동선 콘솔 오류 0, 콘텐츠 완성, 단 데이터가 개인 브라우저에 갇힘)

## 2. 대상과 목적

- **수강생**: 사내 실무자 입문자(비개발). 전문용어 최소화 원칙(예: RAG → "지식검색").
- **강사**: 1인 운영. PC(프로젝터)로 시연, 수강생은 모바일 QR 입장 지원.
- **교육 철학**: "사람이 방향, AI가 초안" — 이론은 쉽게, 강사의 실제 경험담으로 이해를 견인.

## 3. 사용자 여정 (현재 구현된 전체 동선)

```
인트로(4테마 화면보호기: 별똥별·벚꽃·불꽃놀이·함박눈, 테마 선택→클릭 입장)
 → 입장 화면(강의실 입장 버튼 · 스킨 선택 · 진단실 입구)
 → [워프 연출] → 사유의 방(상자 4개: 왜/도구/적용/지속)
 → 상자 클릭 → 카드 5장 부채꼴 → 카드 선택 → 강의 슬라이드
 → 마지막 슬라이드 → "다음 강의 ▶"로 연속 수강 가능
 → 20강 완주 → 축하 연출 → 레벨 업그레이드(회독 시작)
```
- 별도 공간: **진단실**(검사 3종 + 실습 12스테이션, 아래 7절)
- URL 라우팅: 모든 화면이 해시 주소(`#/room`, `#/lecture/7/5` 딥링크 가능), 뒤로가기 씬 단위 동작

## 4. 콘텐츠 현황 (실측)

- **커리큘럼**: 상자 4 × 강의 5 = 20강, 슬라이드 총 **180장**, placeholder **0** (전 강 실콘텐츠)
- 슬라이드 타입: bullets 54 · big(대형 키워드) 39 · split(좌우 비교) 21 · cover 20 · closing 20 · quote 18 · image(도식 SVG) 8
- **분량(실측 추정)**: 강사 풀코스 **약 174분**(상자당 40~50분) · 자가 학습 **약 75분** · 데모 2강(7·8강)만 **약 29분**
- **데모 시연 2강**: 7강 지식검색(RAG)·8강 AI 에이전트 — 강사 실경험 스토리로 재구성됨
  (한방자료 RAG 성공담, "많을수록 좋다" 오해, NotebookLM 이력서 실망담, NanoClaw 여정, 과학문제은행, RAG vs DB 통찰, 휴먼인더루프)
- 각 강의 끝은 다음 강 티저로 연결. 도식 8종은 사유의 방 톤의 자체 제작 SVG.

## 5. 기능 목록 (전부 동작 확인됨)

### 학습 경험
- 슬라이드 엔진 7타입, 키보드(←→·스페이스·Home/End)·버튼·모바일 스와이프
- **이미지 전체화면 확대**: `+`/클릭으로 도식 확대, `-`/Esc 닫기 (프로젝터용)
- **이어보기**: 보다 만 강의는 재진입 시 그 슬라이드부터. 카드·목차에 "▶ 이어보기 6/16" 칩. 끝까지 본 강은 다음번 처음부터
- **전체 목차(☰)**: 20강 한 화면(완료✓·이어보기▶·DEMO), 클릭 즉시 이동
- **⚡핵심 훑기**: 목차에서 각 강의 핵심 문장(대형 키워드·인용)만 펼침(총 77문장), 문장 클릭 = 해당 슬라이드로 점프 — 복습용
- 모바일: QR 입장, 슬라이드 진입 시 가로 전체화면 유도, 세로면 회전 안내, 배경 정적화(배터리)

### 게이미피케이션 (회독 구조)
- HUD: 발견 n/20 · 탐험도 % · 레벨 뱃지
- 완료 판정: **강의 마지막 슬라이드까지 봐야** 점이 켜짐
- **20강 완주 → 축하 연출(골드 폭죽) → "업그레이드" → Lv+1 & 진행도 리셋 = 다음 회독**
- Lv1~5 칭호: Wanderer→Explorer→Thinker→Practitioner→Visionary(통달)
- **Lv 보상 = 스킨 해금**(PC): Lv1 사유의 방 → Lv2 페이퍼 → Lv3 네온 → Lv4 픽셀 → Lv5 블루프린트. 잠긴 스킨엔 "LvN" 뱃지 표시. 모바일은 전부 해금
- 이론 20강 자체는 **절대 잠기지 않음** (게이팅은 보상·심화에만)

### 스킨(테마) 5종
사유의 방(기본·다크 별빛골드) / 페이퍼(라이트) / 네온(다크 글래스) / 픽셀(파스텔 도트) / 블루프린트(설계도) — 색·폰트·배경·모션속도까지 전환, 새로고침 유지

### 운영 편의
- `#/reset` URL로 전체 초기화(시연 준비용), `?view=mobile|pc` 강제, `?unlock=1`(진단실 전층 열기)
- **시연 만료 게이트**: 2026-07-22 23:59 KST 이후 접속 시 종료 안내 화면(index.html 날짜만 수정하면 연장)

## 6. 진단실 (두 번째 공간 — 이론과 별개 축)

"AI로 나·우리 조직을 진단하고 AX 도입 킷을 만든다" — 문제풀이 없음, **완료 = 산출물이 만들어져 저장됨**.

- **검사실(상시 개방)**: 🧠 AI 리터러시 검사(8문항→유형·점수·최약축→추천 강의) · ⚡ AI 네이티브 지수 · 🔐 암묵지 검사
- **1층 AI 손에 익히기**(Lv2 해금): 워밍업/프롬프트 공방/꼬리물기/검증 체크리스트
- **2층 내 일 진단하기**(1층 완료 시): 업무 인벤토리/찾기·만들기 매핑/파일럿 실험/시간 계산
- **3층 조직 진단**(2층 완료 시): AX 건강검진(레이더 차트)/걸림돌 찾기/파일럿 설계/**나의 AX 제안서**
- **제안서**: 앞선 산출물을 자동 조립한 한 장(검사 결과+산출물+💊처방전 3줄+미니 레이더) — 텍스트 복사·인쇄 가능
- 현재 AI 실호출 없음(규칙 기반 목업). "미션"형은 수강생이 외부 AI를 직접 쓰고 결과만 기록하는 설계

## 7. 데이터·기술 구조 (기획 제약의 핵심)

- **저장 방식: 전부 개인 브라우저 localStorage** — 서버·DB·계정 없음
  - 키: 진행도(완료 강의) / 레벨 / 스킨 / 이어보기 위치 / 진단실 진행·산출물(JSON)
- **의미**: 개인 단위로는 데이터가 쌓이고 재사용됨(제안서 자동 조립 등) — 그러나 **강사/조직은 아무것도 볼 수 없음**(수강 현황·진단 결과 집계 불가)
- 콘텐츠는 data.js 하나에 구조화(강의 id·슬라이드 배열) — **기계가 다루기 좋은 형태**라 확장이 쉬움
- 배포: 정적 호스팅이면 어디든(현재 로컬 서버 스크립트 동봉). Netlify 계열 가정 시 서버 기능(Functions)은 "파일 추가 수준"으로 증축 가능(구조 변경 불필요)

## 8. AI 적용 준비도 (점검 결과)

| 후보 | 준비도 | 비고 |
|------|--------|------|
| RAG 조교(수강생 Q&A 봇) | ★★★★☆ | 콘텐츠가 이미 지식베이스급 구조. "출처: 7강 5번 → 바로가기" UX 가능 |
| AI 처방전(진단 해석) | ★★★★☆ | 진단 산출물이 구조화 JSON — 지금의 규칙 3줄을 LLM으로 교체하기 좋음 |
| 관리자 뷰(수강 현황) | ★★☆☆☆ | 수집 백엔드 필요(localStorage 한계). Functions+저장소 추가로 가능 |

## 9. 알려진 한계 / 미결

- 검색 기능 없음(핵심 훑기로 일부 대체)
- 계정·다기기 동기화 없음(브라우저 바뀌면 진행도 처음부터)
- 진단실 AI 미연결(목업), 산출물 개별 내보내기 없음(제안서 경유만)
- 시연 만료 게이트 날짜 하드코딩(7/22) — 정식 서비스 전환 시 제거/정책 필요
- 접근성: reduced-motion 대응은 있음, 스크린리더 최적화는 미검증

## 10. 기획에서 정해야 할 질문 (제안)

1. **정체성**: 데모데이 이후 이 서비스는 무엇이 되나 — ① 강사의 강의 보조도구 ② 수강생 자율학습 서비스 ③ 조직 진단·컨설팅 툴? (지금은 셋이 공존)
2. **데이터 전략**: 조직/강사가 수강·진단 데이터를 봐야 하나? 본다면 익명/실명, 수집 동의는?
3. **AI 우선순위**: RAG 조교 vs AI 처방전 — 어느 쪽이 다음 시연/영업에 더 큰 한 방인가?
4. **진단실 위상**: 이론 20강의 부록인가, 별도 상품(조직 진단 킷)인가?
5. **회독 모델 검증**: Lv·스킨 해금이 실제 재수강을 유도하는가 — 측정 방법은?
6. **배포·과금**: 사내 무료 배포? 외부 강의 상품 번들? 만료 게이트 정책?
