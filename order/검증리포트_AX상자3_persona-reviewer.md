# 검증 리포트 — AX 상자3 (persona-reviewer)

**대상**: `js/data.js` — CURRICULUM.boxes[id:"apply"] (11~15강)
**관점**: AI를 거의 안 써본 비개발 실무 재직자 (마케팅·기획·운영 5년차)
**variant 여부**: 확인 결과 상자3(11~15강)에는 `slidesPersonal`/`slidesVariants` 필드가 없음 — 사용자 전제와 일치, 단일 관점 감사로 진행.
**이월 확인**: 12강(12장)·14강(12장) 13장 하한 미달은 재지적하지 않음.

## 강별 발견

### 11강 · 문서·보고서 자동화
- 발견 없음 — ①②③④ 모두 통과. "회의록 → 임원 보고 1장" 사례(bullets, "사례 · 회의록이 보고서가 되기까지")는 기획·운영 직군 모두에 보편적이고, 03강 검증 습관 회수도 자연스럽다. 과제("이번 주 문서 1개를 초안 루프로")도 오늘 바로 실행 가능.

### 12강 · 마케팅·콘텐츠 실무
- [중] ④ 상자2 연결 — bullets "브랜드다움을 지키는 법" 슬라이드의 `'"자기표절" 점검 — 늘 비슷해지지 않게(07강)'` 항목이 07강을 "복습"으로 인용하지만, 실제 07강 **기본판**(`slides` 배열, 기본 렌더링 경로)에는 "자기표절" 개념이 전혀 등장하지 않는다. 이 개념은 07강의 `slidesPersonal`(경험판, `?variant=personal` 전용, 494번째 줄)에만 존재한다. 기본 경로로 수강한 학습자가 "07강에서 배운 거 맞나?" 하고 되짚어도 찾을 수 없는 회수 실패 사례.
  수용 가능 여부: 개념 자체는 슬라이드 내 짧은 풀이("늘 비슷해지지 않게")로 자기완결적이라 학습 이해에는 지장 없음 — 다만 "(07강)" 인용 표기 자체가 거짓 신호. **완전히 무해하지는 않아 중간 심각도로 분류.**
  제안: "(07강)" 표기를 삭제하거나, 07강 기본판에도 "브랜드 자산 재활용/자기표절 방지" 관련 한 줄을 추가.
- [낮음, 수용 가능] ③ 용어 — bullets "콘텐츠 작업에서 AI가 잘하는 일" 중 `'A/B 후보 — 제목·문구 여러 안 뽑기'`가 별도 풀이 없이 등장. 마케팅 5년차 관점에서는 상식적 용어라 실질 장벽은 낮음.
- ①②는 통과 — "하나의 소식, 다섯 개의 얼굴"(보도자료·인스타·뉴스레터·사내공지·영업멘트) 사례는 마케팅·홍보 실무자에게 매우 구체적이고 현실감 있음. 과제도 오늘 실행 가능.

### 13강 · 데이터 정리와 분석
- [낮음, 수용 가능] ① 사례 현실성 — "사례 · 표 앞에서 얼어붙던 사람"(어느 운영담당, "지점별 실적", "반품률 급증")은 소매·유통업 특화 상황. 지점/반품 개념이 없는 업종(SaaS·서비스업 등) 종사자에겐 "내 얘기"라기보다 "예시일 뿐"으로 느껴질 수 있음. 다만 기법 자체("전월 대비 눈에 띄는 변화 3가지는?")는 업종 무관하게 전이 가능해 실질 문제는 적음.
- [낮음, 수용 가능] ③ 용어 — bullets "데이터 작업에서 AI가 하는 일" 중 `'분석 — "월별 추세 / 이상치 / 상관" 찾기'`에서 "이상치", "상관"이 풀이 없이 등장(통계 용어). 다만 바로 뒤 사례·질문 슬라이드에서는 "전월 대비 눈에 띄는 변화 3가지는?" 같은 평범한 말로 즉시 대체되어 실사용에는 지장 없음.
- ②④는 통과 — 과제("늘 받는 표 1개에 '가장 이상한 지점은?'을 물어보세요")는 오늘 실행 가능하고, 05강(질문법)·03강(검증) 회수가 정확히 대응함(직접 원문 대조 확인).

### 14강 · 이메일·커뮤니케이션 자동화
- [낮음, 수용 가능] ① 사례 현실성 — "사과 메일이 어려웠던 날"(어느 영업담당, "배송 지연으로 화가 난 고객")도 이커머스/물류 특화 상황이며 담당 롤도 "영업담당"으로 페르소나(마케팅·기획·운영)와 정확히 일치하진 않음. 그러나 사과 메일 작성 기법은 업종·직군 무관하게 전이 가능해 실질 위화감은 낮음.
- ②③④는 통과 — 08강(사람 확인 지점) 원문 대조 결과 정확히 일치, 09강(트리거→액션) 재사용도 자연스러움. 과제("가장 쓰기 싫은 메일 1통을 초안부터")는 진입장벽 없이 오늘 실행 가능.

### 15강 · 업무 워크플로우 설계
- 발견 없음 — ①②③④ 모두 통과. "주간 보고의 재설계" 사례는 특정 업종색이 없는 범용 사무 상황이라 오히려 상자3 사례 중 가장 보편적. 09·11·03강 회수 모두 정확. 과제("업무 1개를 5단계로 쪼개 담당 적기")는 도구 없이도 실행 가능해 진입장벽이 가장 낮음. 01강 "반복 업무 1개" 스레드도 정확히 회수됨(원문: "01강부터 적어온 그 '반복 업무'").

## 총평 (3줄)
1. 상자3의 핵심 사례 5개는 대체로 마케팅·기획·운영·영업 직군을 고루 배치해 지정 관점과 잘 맞았으나, 13·14강 사례(지점·반품·배송지연)는 유통/이커머스 쪽에 다소 기울어 있음 — 다만 기법 전이 가능성 덕에 심각도는 낮음.
2. 가장 눈에 띄는 실질 발견은 12강의 "(07강)" 자기표절 인용이 기본판 07강에 실제로 존재하지 않는 개념을 가리키는 것 — 상자2→상자3 연결(④)에서 유일하게 확인된 회수 실패이며, 나머지 04·05·08·09·03강 회수는 모두 원문과 정확히 일치했다.
3. 과제 실행 가능성은 5개 강 전부 통과(도구 접근 전제가 이미 확보된 위치에서 자연스럽게 이어지며, 15강 과제는 도구 없이도 가능해 진입장벽이 가장 낮음).
