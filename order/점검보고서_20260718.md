## 파트 4 · Lv 게이팅 감사 (질문 3)

- **Lv 산정 공식(실측)**: 20강 전부 완료(각 강은 *마지막 슬라이드까지 봐야* 완료) → "⬆ 업그레이드" 버튼 → `Level.up()`(+1, 최대 5) → **진행도 리셋 = 새 회독 시작**. Lv1 시작, Lv5 = "✦ 통달".
- **잠긴 기능과 해금 조건(실측)**:

| 잠긴 것 | 조건 | 확인 |
|---------|------|------|
| 스킨 paper | Lv2 | 실측: Lv1에서 `Skin.set('paper')` 호출도 거부(sayu 강제) → Lv2 승급 직후 적용 성공 |
| 스킨 neon / pixel / blueprint | Lv3 / Lv4 / Lv5 | 코드 SKIN_ORDER + 실측 잠금 클래스 |
| (모바일은 스킨 전부 해금) | — | `IS_MOBILE`이면 5종 전부 |
| 진단실 1층(브랜치) | Lv2 | 파트 6 실측 |

- **핵심 콘텐츠(이론 20강): 잠기지 않음** ✅ — 게이팅은 전부 '보상(스킨)·심화(진단실)'에만.
- **해금 조건 화면 표시**: ⚠️ 스킨은 잠금 버튼의 **hover 툴팁**("LvN 달성 시 해금")뿐 — 터치 기기·초견 사용자는 이유를 모를 수 있음. 진단실은 🔒 문구로 **상시 명시**(잘 됨).
- **해금 순간 피드백**: ✅ 완주 오버레이(축하+승급 버튼) → 승급 시 랭크 뱃지 pop, Lv5 통달 전환 연출.

**평가 — 잘된 점**: 강제 잠금이 아닌 보상형, 회독 루프(완주→리셋→재수강)와 결합된 일관된 설계, `#/reset` 운영용 초기화 URL. **빠진 점**: 스킨 잠금 사유의 발견성(툴팁 의존), 업그레이드 시 진행도 리셋임을 사전 경고하지 않음(버튼 title뿐).

## 파트 8 · 종합 보고

### 1) 수준 한 줄 평가
**"실사용 v1 직전의 고급 데모"** — 기능 완성도(콘텐츠 180장 placeholder 0, 전 동선 콘솔 오류 0, 게이미피케이션·회독 루프·진단실 산출물 루프 완비)는 v1 수준이나, ① 데이터가 개인 브라우저에 갇혀 있고 ② AI가 실제로 연결되지 않았으며 ③ 시연 만료 게이트가 박힌 "행사용 배포" 상태라는 점에서 상용 전 단계.

### 2) 질문 6개 실측 답변
1. **몇 분짜리인가** — 강사 풀코스 **약 174분**(상자당 40~50분×4세션), 자가 학습 **약 75분**. 데모데이(7·8강)는 **약 29분**. 20강의 분량 편차가 작아(8~10장, 데모 2강만 14·16장) 세션 설계가 쉬움.
2. **반복학습에 좋은가** — 절반. 회독(Lv) 루프·딥링크·다음 강 이어가기·새로고침 위치 복원은 갖췄지만, **재진입 이어보기 저장·검색·요약 모드·전체 목차가 없어** "다시 찾아보는" 용도로는 클릭이 많다(재열람 4클릭).
3. **Lv 게이팅 유효한가** — 유효. 핵심 콘텐츠는 안 잠그고 보상(스킨 5종 순차 해금)·심화(진단실 1층)만 잠갔으며, 완주→승급→리셋의 회독 루프와 맞물린다. 약점은 잠금 '이유'의 발견성(hover 툴팁 의존)과 승급 시 리셋 사전 고지 부족.
4. **진단실 상태** — 검사 3종+12스테이션 전 구현·전 동작(저장·복원·게이팅·제안서·처방전·레이더·복사·인쇄). 남은 일: AI 실호출 연결, 검사↔완료 카운트 정리, 개별 산출물 내보내기. **main 병합은 충돌 0으로 실증됨.**
5. **DX인가** — 개인 수준은 예(구조화 콘텐츠 + 쌓이고 재사용되는 데이터 루프 6키), 조직 수준은 아니오(수집 채널 부재로 브라우저 격리). 서버 한 겹이 판정을 바꾼다.
6. **AI는 어디에** — ① RAG 조교(콘텐츠 구조가 이미 지식베이스 급 — 최우선) ② 진단 결과 AI 처방전(axp_out JSON이 프롬프트 투입 최적) ③ 관리자 뷰(Functions+저장소 추가 필요). 셋 다 기존 구조 변경 없이 증축 가능.

### 3) 발견 버그·이슈 (수정하지 않음)
| # | 심각도 | 내용 |
|---|--------|------|
| B1 | **High** | `serve.py`가 단일 스레드(`TCPServer`) — 실브라우저의 동시 연결에 **서버가 멈춤(행)**. 본 점검 당일 실제 재현(포트는 살아있으나 무응답). `ThreadingHTTPServer`로 1줄 교체 필요 |

### 4) 개선 우선순위 Top 5 (효과 대비 작업량)
1. **serve.py 멀티스레드화** — 1줄 수준으로 시연 중 서버 멈춤(B1) 제거. 데모데이 리스크 직결.
