## ① 경험판 프레이밍 슬라이드 추가 (07·08강 slidesPersonal)

**판단**: 고유명사·인프라 용어가 문제인 게 아니라, **"외워야 한다는 부담"**이 문제다. 초입에 부담을 해제하는 한 장을 넣으면 뒤따르는 모든 용어가 배경으로 물러난다.

각 경험판의 **cover 바로 다음**에 삽입:

```js
// 07강 경험판용
{ type: 'bullets', title: '먼저, 부담 하나 내려놓고 갑니다',
  subtitle: '이제부터 나올 도구 이름들에 대하여',
  items: [
    '지금부터 제가 쓴 도구 이름이 몇 개 나옵니다',
    '외우실 필요 없습니다 — 여러분 회사엔 다른 도구가 맞을 수 있습니다',
    '중요한 건 "무엇으로"가 아니라 "무엇을 했고, 왜 그렇게 했나"입니다',
    '이름은 흘려들으시고, 판단의 흐름만 따라오세요'
  ] },
```

```js
// 08강 경험판용 (같은 취지, 문구만 변주)
{ type: 'bullets', title: '도구 이름은 흘려들으세요',
  subtitle: '오늘 볼 것은 제품이 아니라 설계입니다',
  items: [
    '제가 쓴 도구 이름이 여럿 나오지만, 외울 필요는 없습니다',
    '도구는 6개월이면 바뀝니다 — 남는 건 설계 방식입니다',
    '보실 것: 무엇을 보게 했고, 어떤 도구를 줬고, 어디서 멈추게 했나',
    '그 세 가지만 가져가시면 오늘 강의는 성공입니다'
  ] },
```

- 삽입 후 경험판 장수 재계산·보고(07강 14→15, 08강 16→17 예상).
- **범용판(slides)은 무변경.**

## ② 개념 용어만 인라인 한 줄 풀이 (경험판)

도구 **고유명사는 그대로 두고**(①이 커버), **개념 용어**만 첫 등장 위치에 괄호 한 줄:

- `RAG` → 첫 등장에 `RAG(내 자료에서 찾아 답하기)` — 07강 범용판의 풀이 표현과 **동일한 문구**로 통일(라운드 1·2에서 반복 지적된 "같은 개념, 다른 깊이" 패턴 해소)
- `MCP` → `MCP(도구를 AI에 연결하는 규격)`
- `게이트웨이` → `게이트웨이(요청을 받아 넘겨주는 중간 창구)`
- `엔드포인트`·`빌더` → 부록 슬라이드이므로 **한 번만** 짧게 풀이하거나, 문장에서 자연스럽게 생략 가능하면 생략
- `KPI`·`VOC` → 일반 경영 약어이므로 **풀이하지 않음**(§3 보류 항목의 잠정 기준: 경영 일반 약어는 예외)

> 원칙: 한 강에 인라인 풀이는 **3~4개까지**. 그 이상이면 용어 자체를 문장에서 덜어내는 쪽을 검토(보고).

## ③ 08강 "정리+과제" 구조 정렬

과제가 "생각해보기" 슬라이드에 끼어 있고 제목·배치가 다른 강과 다름 → **다른 강과 동일한 형식**으로 정렬:
- 마지막에서 두 번째: `'한 장 정리 + 오늘의 과제'` (정리 3항목 + `📝 과제:` 1항목)
- 그 앞: `'생각해보기'` (질문 3항목, 과제 제거)
- 항목 내용은 기존 문구를 최대한 재사용 — **구조만 정렬**. 범용판/경험판 중 어긋난 쪽만 수정하고 어느 쪽을 고쳤는지 보고.

## ④ 헌법 §2 경험판 조항 신설 (AX판)

`docs/톤앤매너.md` AX판 §2(어투)에 추가:

> **경험판(variant) 조항** — 강사 1인칭 경험담 버전은 다음을 허용·요구한다.
> ① 1인칭 서술("제가 만들었을 때") 허용 — 범용판의 3인칭 서술 규정 예외.
> ② 특정 제품·도구 고유명사 등장 허용. 단 **초입에 "외울 필요 없다"는 프레이밍 슬라이드를 반드시 둔다.**
> ③ 개념 용어(기술 개념)는 범용판과 **동일한 풀이 문구**를 쓴다 — 같은 개념이 판에 따라 다르게 설명되지 않게.
> ④ 경영 일반 약어(KPI·VOC·ROI 등)는 풀이 대상이 아니다.
> ⑤ 경험판도 규격 요소(사례·오해 셋·생각해보기·한 장 정리+과제)를 따른다 — **다만 과제 유무는 보류항목에서 별도 결정 중**.
