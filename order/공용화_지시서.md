## ① site-config.js 분리

새 파일 `js/site-config.js` — 사이트를 갈아탈 때 이 파일만 바꾸면 되도록:

```js
// 개념 — 실제 키는 코드 조사 후 확정하되 이 범위를 커버
const SITE_CONFIG = {
  course: 'ax',                      // LMS 과정 식별자 (②에서 사용)
  siteName: '사유의 방',
  siteSubtitle: 'AX 입문 20강',
  defaultSkin: 'paper',
  availableSkins: ['sayu','paper','neon','pixel','blueprint'],
  introThemes: ['star','sakura','fireworks','snow'],
  fxLevel: 'full',                   // 연출 강도: full | calm (calm=완주 폭죽·워프 등 절제)
  practiceRoom: true,                // 진단실 노출 여부 (AI 사이트는 false 가능)
  finalMessage: '사람이 방향, AI가 초안'
};
```

- 현재 코드에 흩어진 위 값들의 **하드코딩을 찾아 SITE_CONFIG 참조로 치환**(기능 동일). 목록에 없어도 "사이트마다 달라질 값"을 발견하면 편입하고 보고.
- `fxLevel: 'calm'`은 이번에 **동작만 구현**(폭죽·워프·등장 연출을 간소화된 페이드로 대체) — 기본은 'full'이라 현 사이트 경험 무변경. AI 사이트에서 쓸 준비.
- `index.html`에서 사이트명·부제가 SITE_CONFIG를 읽는지 확인(타이틀 태그 포함).

## ② LMS course 구분 (다과정 대응)

**사람이 먼저 (Supabase SQL Editor):**
```sql
alter table events add column course text not null default 'ax';
```
(기존 데이터 없음 — 0건 상태라 안전. 실행 결과 보고에 기재.)

**CC 작업:**
- 프론트 텔레메트리: 모든 이벤트에 `course: SITE_CONFIG.course` 포함.
- `track` 함수: course 검증(2~20자 영소문자) 후 insert에 포함.
- `_shared/aggregate.js`: course 필터 지원. `stats`·`brief`에 `?course=` 파라미터(기본: 전체).
- 대시보드(#/admin): 요약 헤더에 **과정 필터**(전체/ax — 값은 데이터에서 자동 추출, 반 필터와 병행). 브리핑 생성 시 현재 과정 필터 반영(레이어 제목에 표기).

## ③ 입장 화면 유틸 재편 — B안 (승인된 목업 기준)

**⚙️ 톱니 폐지 → 성격별 아이콘 2개** (우상단):

- **🎫 내 정보** (아이콘: 신분증/badge 계열)
  - 레이어 내용: 수강 코드 입력·안내 문구·변경/제거 (기존 코드 UI 이동)
  - **코드 등록 후엔 아이콘 대신 코드 뱃지("A반-07")가 그 자리에** — 탭하면 같은 레이어. HUD의 기존 🎫 뱃지와 중복되면 입장 화면 쪽으로 일원화.
  - `?join=` 링크는 이 레이어를 자동 오픈(기존 동작 유지, 대상 레이어만 변경).
- **🎨 테마** (아이콘: 팔레트)
  - 레이어 내용: 스킨 5종 그리드(잠금 Lv 뱃지 포함, 기존 선택기 이동)
  - **레이어 하단에 "진행 기록 초기화"** (구분선 아래 작게, 확인창 1번 — 첫 화면에서 제거, `#/reset` URL은 유지)

- 레이어 동작·스타일은 기존 바텀시트/패널 시스템 재사용(열기·닫기 1탭·ESC·백드롭).
- 화면 요소 상한: [강의실 입장] + [진단실(해금 시)] + 🎫 + 🎨 = 4개. UX_원칙.md의 "최소주의" 조항을 이 구성으로 갱신(⚙️ 표기 제거).
- 5개 스킨·375px에서 아이콘·뱃지 대비 확인(다크 스킨에서 밝은 톤).
