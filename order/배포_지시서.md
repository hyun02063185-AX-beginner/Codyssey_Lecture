# 배포 지시서 — 웹에 올려 링크로 공유하기 (Netlify)

> 위치: `Last_Lecture/order/배포_지시서.md` · 경로는 프로젝트 루트 기준.
> **목표**: 다른 사람이 브라우저에서 열어볼 수 있는 **공개 URL**을 만든다.
> 저장소는 **비공개 그대로** 두고, 사이트만 공개한다.

---

## 이 방식을 고른 이유

- 이 프로젝트는 **빌드 없는 정적 사이트**(html/css/js) → 어디든 그대로 올리면 됨.
- **Netlify 무료 플랜**: 비공개 GitHub 저장소를 연결해도 **사이트만 공개** 가능. 기간 제한 없음.
- `git push` 하면 **자동 재배포**.

> 참고: 정적 사이트라 브라우저 F12로 슬라이드 텍스트는 보인다(어떤 호스팅이든 동일). 저장소 자체가 열리지 않을 뿐.

---

## 0. 사전 확인

- 최신 작업이 **원격에 push** 돼 있어야 그 내용이 배포된다.
  ```bash
  cd Last_Lecture
  git status
  git add -A && git commit -m "배포 전 최신 반영"
  git push
  ```
- 로컬에서 정상 동작 확인(20강·스킨·인트로·카드 선택).

---

## 1. Netlify 연결 (브라우저에서, 사람이 직접)

> 계정 생성·로그인·권한 승인은 **사용자가 직접** 해야 한다(CC/AI가 대신 로그인하지 않음).

1. `https://netlify.com` → **Sign up** → **GitHub 계정으로 로그인**.
2. **Add new site → Import an existing project** 선택.
3. **GitHub** 선택 → 권한 승인 → 저장소 목록에서 **`Last_Lecture`** 선택.
   - 비공개 저장소가 안 보이면, 권한 화면에서 해당 저장소 접근을 허용.
4. **빌드 설정** — 이 프로젝트는 빌드가 없다:
   - **Build command**: (비워둠)
   - **Publish directory**: `.` (저장소 루트. `index.html`이 루트에 있으므로)
   - Branch: `main` (실제 기본 브랜치명에 맞출 것)
5. **Deploy** 클릭 → 1~2분 뒤 임시 주소(`random-name-123.netlify.app`) 생성.

---

## 2. 주소 이름 바꾸기 (선택)

- Site configuration → **Change site name** → 원하는 이름(영문/숫자/하이픈).
- 예: `sayu-room` → `https://sayu-room.netlify.app`
- 이 주소를 공유하면 끝.

---

## 3. 공유 후 확인 (중요)

배포된 URL을 **다른 브라우저(또는 시크릿 창·휴대폰)** 로 열어 확인:

- [ ] 인트로 4테마 화면보호기 → 선택 → 전체화면 → 클릭 → 강의실 입장
- [ ] 사유의 방(상자 4개) → 카드 선택 → 슬라이드 진입
- [ ] **20강 전부 내용 표시**(플레이스홀더 없음)
- [ ] 스킨 5종(페이퍼·네온·픽셀·블루프린트·사유의 방) 전환
- [ ] 폰트·이미지가 깨지지 않음 (경로 문제 점검 → 아래)
- [ ] 휴대폰에서도 열림
- [ ] 콘솔(F12) 에러 0건

---

## 4. 자주 나는 문제

- **화면이 하얗게 뜸 / 리소스 404**
  → 경로가 절대경로(`/css/style.css`)라 그럴 수 있다. 이 프로젝트는 루트 배포라 대개 괜찮지만, 문제가 나면 **상대경로**(`css/style.css`)로 통일.
- **폰트 안 뜸**: CDN 링크가 https인지 확인(혼합 콘텐츠 차단).
- **최신 내용이 아님**: push 됐는지 확인 → Netlify의 **Deploys** 탭에서 최신 배포 성공했는지 확인.
- **저장소가 목록에 없음**: Netlify의 GitHub 권한에서 해당 저장소 접근 허용.

---

## 5. 이후 운영

- 코드를 고치고 `git push` → **자동 재배포**(별도 작업 없음).
- 데모 끝나고 내리고 싶으면: Netlify에서 사이트 **삭제** 또는 비공개 처리.
