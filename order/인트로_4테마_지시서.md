# CC 작업 지시서 — 인트로 4테마 화면보호기 + 4분할 선택

위치: `Last_Lecture/order/인트로_4테마_지시서.md` · 경로는 프로젝트 루트 기준. 로컬 렌더로 직접 보며 반복 검증(CC 실행 가능).

## 목표
시작 화면을 4테마 화면보호기로 확장한다.

- **4분할 랜딩** — 한 화면에 2×2로 4테마가 동시에 흐름: ① 별똥별(shooting stars) ② 벚꽃(cherry blossoms) ③ 불꽃놀이(fireworks) ④ 함박눈(snow)
- **선택** — 한 칸을 클릭하면 그 테마가 전체화면으로 확장(나머지는 사라짐). 이 상태가 "화면보호기".
- **입장** — 전체화면에서 한 번 더 클릭하면 기존 "강의실 입장(워프)" 화면으로 페이드인.

즉 흐름: **4분할 → (클릭) 테마 전체화면 → (클릭) 강의실 입장 → 사유의 방.**

이 인트로 테마 4종은 UI 스킨 5종(paper·neon·pixel·blueprint·sayu)과 **별개**다. 스킨 시스템·`data-skin`·스킨 선택기는 건드리지 않는다.

## 작업 순서
1. `index.html`·`css/style.css`·`js/main.js`(배경 캔버스/씬 전환 로직)를 먼저 읽고 현재 시작 씬 구조를 파악한다. 기존 별/성운 캔버스 엔진이 있으면 재사용·확장.
2. 아래 "구현 사양"대로 4분할 랜딩 → 전체화면 → 입장 흐름을 구현.
3. 파티클 엔진은 하나로 통합하고 테마별 설정(config)만 다르게.
4. 기존 씬(강의실 입장·사유의 방·슬라이드)·스킨·엔진 로직은 깨지 않게.
5. 로컬 서버로 4테마·전환·성능·입장까지 직접 검증(아래 "검증 루프").

## 구현 사양

### A. 통합 파티클 엔진 (테마 = 설정)
`requestAnimationFrame` 루프 하나로 도는 재사용 파티클 시스템. 테마별 config:
- **별똥별** — 어두운 밤하늘 + 옅은 별 + 가끔 대각선으로 긋는 유성(꼬리). (기존 별 캔버스 있으면 확장.) 색: 흰~옅은 골드. 배경 `#0A0A14`.
- **벚꽃** — 분홍 꽃잎이 좌우로 흔들리며(사인 스웨이) 회전하며 천천히 낙하. 색: `#F7C8D6`~`#F4A6C0`. 배경: 어스름한 자주/남보라 `#1A1420` 또는 다크.
- **불꽃놀이** — 어두운 하늘 + 주기적으로 발사→터짐→중력 낙하→페이드하는 색색 불꽃. 색: 다색(골드·시안·핑크·그린). 배경 `#0A0A14`. 은은하게(작고 느리게) — 명상 톤 유지 권장.
- **함박눈** — 크고 부드러운 눈송이가 살짝 옆으로 흘리며 느리게 낙하. 크기·투명도 변주, 약한 블러. 색: 흰~옅은 하늘빛. 배경: 짙은 남색 밤 `#0B1626`.

공통: `prefers-reduced-motion: reduce`면 입자 최소/정지, 정적 배경으로.

### B. 4분할 랜딩
- 화면을 2×2로 나눠 각 칸에서 해당 테마를 렌더. 칸마다 작은 라벨(별똥별/벚꽃/불꽃놀이/함박눈)과 hover 하이라이트.
- 성능: 미리보기 칸에선 입자 수를 대폭 줄임(정식 대비 ~1/3). 렌더 루프는 하나로, 4칸을 그 안에서 그림(4개 setInterval 금지). 탭 숨김 시 `visibilitychange`로 일시정지.
- 구현은 4개 작은 `<canvas>` 또는 1개 캔버스를 4영역으로 클립 — CC가 성능 유리한 쪽 선택.
- 접근성: 각 칸 `tabindex`, 방향키 포커스 이동 + `Enter` 선택.

### C. 선택 → 전체화면
- 칸 클릭 → 그 테마가 전체화면으로 부드럽게 확장(스케일/opacity 트랜지션 ~.5s), 나머지 3칸 페이드아웃.
- 전체화면에선 그 테마를 풀 입자 수로 렌더(화면보호기 품질).
- 하단에 은은한 안내: "화면을 클릭하면 입장" (몇 초 뒤 서서히 나타나게).
- (선택) 좌상단 작은 "← 테마 다시 고르기"로 4분할 복귀.

### D. 클릭 → 강의실 입장
- 전체화면 아무 곳이나 클릭 → 인트로를 페이드아웃하고 기존 "강의실 입장(워프)" 씬으로 페이드인. (main.js의 기존 씬 전환/워프 로직을 재사용. 새로 만들지 말 것.)
- 안내 텍스트 클릭도 동일 동작.

### E. 모듈성 (테마 추가/삭제 쉽게)
- 테마는 배열/맵으로 관리(`INTRO_THEMES = [star, sakura, fireworks, snow]`). 하나 빼거나 더하기 쉽게.
- (사용자 방침: 일단 4개 넣고, 별로면 나중에 뺀다.)

## 가드레일
- UI 스킨 시스템(5종)·`data-skin`·스킨 선택기 변경 금지. 인트로 테마와 별개.
- 기존 씬(강의실 입장·사유의 방·슬라이드)·room.js·slides.js·데이터 미변경. 이번 작업은 시작 인트로에 한정.
- 진행도 저장 localStorage 키 재사용 금지(필요 시 인트로용 별도 키).
