# CC 작업 지시서 — 히든코드 체계 (치트를 수강 코드 입력칸으로 통합)

> 위치: `AX_Lecture/order/히든코드_지시서.md` · **양쪽 저장소 작업**(엔진 공용 — 코드 입력 처리부).
> 목적: URL 파라미터·해시로 흩어진 강사용 치트를 **🎫 코드 입력칸의 히든코드**로 통합 — 모바일에서 쓰기 쉽고, 수강생에게 노출되지 않게. 권장 모델: 높음.
> 전제: 코드방식_서버설정_지시서 완료 후(코드+이름 2칸 구조 위에 얹음). 미완료면 순차 실행.

---

## 설계 원칙

- **접두어 = `무대뒤.`** (마침표 포함) — 반코드 형식과 충돌 불가, 우연 입력 확률 0, 은유 정합(무대 뒤 = 스태프 공간).
- 히든코드는 **코드 칸에만** 입력(이름 칸 무관, 이름 비어 있어도 동작). 인식 시 **수강 코드로 저장하지 않고** 명령으로 처리 — 텔레메트리 전송 없음.
- 입력 성공 시 짧은 토스트(예: "🎬 무대 뒤: 스킨 전체 해금")로 피드백 후 레이어 자동 닫힘. 실패(미등록 명령)는 **아무 반응 없음**(존재를 숨긴다 — 오류 메시지 금지).
- 기존 URL 방식은 **당분간 병행 유지**(치트시트에 둘 다 기재 — 데스크톱에선 URL이 빠를 때도 있음). 단 ③의 인트로 테마는 예외(아래).

## ① 히든코드 명령 세트

| 히든코드 | 동작 | 비고 |
|---|---|---|
| `무대뒤.스킨` | 전 스킨 즉시 해금 (세션 아닌 저장 — 재방문 유지) | 기존 `?unlock=1`의 스킨 부분 |
| `무대뒤.잠금` | 해금 치트 원복(레벨 기준으로 되돌림) | 시연 후 정리용 |
| `무대뒤.진단실` | 진단실 즉시 해금 (AX만 — 첫걸음은 무시) | 기존 unlock의 진단실 부분 |
| `무대뒤.초기화` | `#/reset`과 동일 — **확인창 1번 유지** | 위험 치트는 확인선 유지 |
| `무대뒤.경험판` | `?variant=personal` 토글 (AX 7·8강) | 재입력 시 해제 |
| `무대뒤.테마` | **기존 4분할 테마 선택 화면을 연다**(실시간 미리보기 그리드) → 고르면 저장 | ② 참조 — 사이트별 가용 테마만 표시 |
| `무대뒤.레벨.1~3` | 레벨 강제 설정(시연용) | 진행 기록은 유지, Lv만 |
| `무대뒤.관리` | `#/admin` 이동 | 폰에서 대시보드 열 때 |
| `무대뒤.목록` | 사용 가능한 히든코드 목록 토스트/패널 | 강사가 까먹었을 때 |

- 명령 파서는 SITE_CONFIG 기반으로(사이트별 가용 명령·테마 목록이 다름 — 첫걸음: 진단실 없음, 테마는 눈·벚꽃, 경험판 없음). 미가용 명령은 무반응.
- 구현은 코드 입력 처리부 한 곳에 집중(공용 엔진) — 명령 정의는 config/데이터로 분리해 추가가 쉽게.

## ② 테마 선택 화면 — 제거가 아니라 "숨김 + 호출"

> **주의: 기존 4분할 선택 화면(테마별 실시간 미리보기 그리드)을 삭제하지 않는다.** 기본 동선에서만 빼고, 히든코드로 불러오는 강사 전용 화면으로 전환한다.

- **기본 진입 동선**: 인트로 → 저장된(또는 기본) 테마가 **바로 전체화면 화면보호기**로 재생 → 클릭 → 강의실 입장. 수강생은 4분할 선택 단계를 보지 않는다.
- **`무대뒤.테마` 입력 시**: 🎫 레이어를 닫고 **기존 4분할 선택 화면을 표시** → 칸 선택 → 그 테마를 **저장(재방문 유지)** → 기존 흐름대로 전체화면 → 클릭 → 입장.
- 사이트별 가용 테마만 칸에 표시(AX 4종 / 첫걸음 2종 — SITE_CONFIG.introThemes). 첫걸음처럼 2개면 2칸 레이아웃 유지(기존 마크업 그대로).
- 선택 화면의 성능 최적화(미리보기 입자 절감·단일 루프·탭 숨김 정지)는 **기존 구현 유지** — 이번에 손대지 않는다.
- 결과적으로 인트로가 **첫 화면 최소주의(UX 원칙)에 부합**해짐(수강생 선택 단계 0) — 점검 체크리스트로 확인.

## ③ 문서 — 치트시트가 유일한 참조처

- `docs/운영자_치트시트.md` 개편(양쪽): **히든코드 표**를 최상단 섹션으로(위 표 + 사이트별 가용 여부), URL 방식은 보조로 병기. "히든코드는 수강생에게 알려주지 않는다" 한 줄.
- `docs/서버_실행_가이드.md`·운영매뉴얼과 상호 참조 확인. §7 기록(엔진 공용부 변경).
