# 배포용 기술스택 정리 (사유의 방 · AX 20강)

> 클라우드 제품을 고르기 위한 요약. **결론부터: 이 사이트는 100% 정적(static)이라 서버·DB·런타임이 전혀 필요 없다. "정적 웹 호스팅"만 있으면 된다.**

## 1. 무엇으로 만들어졌나
| 구분 | 내용 |
|---|---|
| 프론트 | **순수 HTML + CSS + 바닐라 JS(ES2015+)** — 프레임워크·빌드·번들러 없음 |
| 에셋 | SVG 도식(assets/), 아이콘(이모지/inline) — 이미지 파일 최소 |
| 라우팅 | **해시 라우팅**(`#/room`, `#/lecture/7/3` …) — 모든 요청이 `index.html` 하나로 처리됨 |
| 상태 저장 | **브라우저 localStorage**(진행도·레벨·스킨) — 서버 DB 없음 |
| 백엔드 | **없음** (API·인증·서버 로직 0) |
| 빌드 단계 | **없음** (소스 = 배포물, `npm build` 불필요) |

## 2. 클라우드에 필요한 것 / 필요 없는 것
**필요한 것 (이게 전부):**
- **정적 파일 호스팅** + **HTTPS**
- (선택) CDN — 대부분의 정적 호스트에 기본 포함
- (선택) 커스텀 도메인 — 대부분 무료 TLS 제공

**필요 없는 것 (착오 방지):**
- ❌ 서버 런타임(Node/Python/PHP …) — `serve.py`·`http.server`는 **로컬 개발 전용**
- ❌ 데이터베이스(Postgres/MySQL/Redis …)
- ❌ 컨테이너/VM/쿠버네티스
- ❌ 환경변수·시크릿·API 키
- ❌ SPA 리라이트 규칙 — 해시 라우팅이라 서버 rewrite 설정조차 불필요

## 3. 런타임 외부 의존성 (호스트가 아니라 "사용자 브라우저"가 불러옴)
폰트를 CDN에서 로드한다. **호스트엔 부담 없음**, 다만 사용자 브라우저가 아래 도메인에 접속 가능해야 폰트가 제대로 뜬다.
- Google Fonts (`fonts.googleapis.com`, `fonts.gstatic.com`) — Gaegu·Nanum Myeongjo·Gowun Batang·Orbitron·IBM Plex Sans KR·Space Grotesk·Press Start 2P
- jsDelivr (`cdn.jsdelivr.net`) — Pretendard·Galmuri

> (선택) 오프라인/폐쇄망·안정성이 중요하면 폰트를 프로젝트 안에 **셀프호스팅**으로 바꿀 수 있다. 지금은 필수 아님.

## 4. 추천 클라우드 제품 (정적 호스팅 · 무료 티어)
| 제품 | 왜 / 특징 | 비고 |
|---|---|---|
| **GitHub Pages** | 이미 GitHub에 레포 있음 → 켜기만 하면 배포. 무료·HTTPS·커스텀도메인 | ★비공개 레포는 Pages에 Pro 필요, 또는 레포 공개 전환 |
| **Cloudflare Pages** | Git 연결 시 push마다 자동 배포. 글로벌 CDN·무료·빠름 | 설정 거의 0 |
| **Netlify** / **Vercel** | Git 연결 or 드래그 배포. 무료 티어 넉넉·자동 HTTPS·CDN | 정적 사이트 최적 |
| **Firebase Hosting** | CLI 배포·CDN·HTTPS. 구글 생태계면 편함 | `firebase deploy` |
| AWS S3 + CloudFront | 통제력↑·엔터프라이즈. 대신 버킷+배포+인증서 설정 필요 | 이 규모엔 과함 |

**추천:** 레포가 이미 GitHub에 있으니 → **GitHub Pages**(공개 가능하면 가장 간단) 또는 **Cloudflare Pages / Netlify / Vercel**(레포 연결 → push마다 자동배포). VM·컨테이너·DB 다 불필요.

## 5. 배포 전 체크리스트 (중요)
- [ ] **`js/main.js`의 `TEST_FILL_ALL = false`로 변경** — 지금은 테스트용(20강을 끝까지 보면 전체 완주 처리)이라 실서비스엔 반드시 꺼야 20강 전부를 봐야 완주가 되는 정상 동작이 된다
- [ ] `serve.py` · `server_session.txt` · `order/` 문서 등은 개발용 — 배포에 포함돼도 무해하나 필요는 없음(서버 재시작 초기화 기능은 로컬 전용, 클라우드에선 동작 안 함 = 실사용자 진행도 유지되는 게 정상)
- [ ] 커스텀 도메인 쓸 경우 DNS + 무료 TLS 연결
- [ ] assets/ 의 한글 파일명(예: `7강_의미검색.svg`)은 UTF-8 URL 인코딩으로 서빙됨 — 위 추천 호스트는 모두 정상 처리(혹시 문제 시 ASCII 파일명으로 교체 가능)
- [ ] 배포 후 `#/lecture/8/3` 같은 딥링크·새로고침 정상 동작 확인(해시 라우팅이라 문제 없음)

## 6. 한 줄 요약
> **정적 사이트 = "파일만 올리면 끝".** GitHub Pages나 Cloudflare/Netlify/Vercel 같은 정적 호스팅 하나 고르면 되고, 서버·DB·런타임 고민은 할 필요가 없다.
