---

## 목표

시작화면(index)에서 사용자가 **4가지 스킨**을 골라 전체 페이지 테마를 바꾸게 한다.

| 스킨 | 값(`data-skin`) | 성격 |
|------|------|------|
| 미니멀 라이트 (페이퍼) | `paper` | **첫 진입 기본**. 밝고 차분, 프로젝터용 |
| 다크 네온 (글래스) | `neon` | 현재 스킨 유지 |
| 레트로 픽셀 (8비트 터미널) | `pixel` | 도트/CRT 감성, 유머 |
| 블루프린트 (설계도) | `blueprint` | 네이비+시안 라인아트, "설계자" 컨셉 |

- **기본값 = `paper`** (localStorage에 저장된 값 없을 때).
- 고른 스킨은 localStorage에 저장, 새로고침·씬 전환 후에도 유지.

---

## 작동 아키텍처

1. `css/style.css`에서 **색·폰트·질감 관련 값**을 CSS 변수로 뺀다. (이미 `:root` 변수를 쓰고 있으면 그대로 활용)
2. 스킨별로 같은 변수명을 재정의하는 블록을 만든다:
   ```css
   :root[data-skin="paper"]     { --bg: …; --text: …; … }
   :root[data-skin="neon"]      { … }
   :root[data-skin="pixel"]     { … }
   :root[data-skin="blueprint"] { … }
   ```
   레이아웃·크기·애니메이션 같은 **구조 CSS는 스킨 밖에** 그대로 둔다.
3. `<html>`(document.documentElement)에 `data-skin` 속성을 붙였다 뗐다 하며 전환.
4. 시작화면에 스킨 선택 UI를 얹고, 클릭 시 즉시 반영 + 저장.

---

## 작업 순서 (반드시 이 순서로)

1. **먼저 `css/style.css`와 `js/main.js`를 읽어라.**
   - 기존 색이 변수인지 하드코딩인지 확인. 하드코딩이면 먼저 변수로 승격.
   - 현재 네온 스킨의 실제 값들을 그대로 `[data-skin="neon"]` 블록으로 옮긴다(현재 모습 보존).
2. 아래 "스킨 팔레트"의 값으로 `paper` · `pixel` · `blueprint` 블록을 만든다.
3. 시작화면(시작 씬)에 "스킨 선택기 UI 사양"대로 선택 UI를 넣는다.
4. `js/main.js`에서:
   - 로드 시 `localStorage.getItem('axRoomSkin')` → 없으면 `'paper'` → `document.documentElement.dataset.skin`에 반영.
   - 선택기 버튼 클릭 → `dataset.skin` 갱신 + `localStorage.setItem('axRoomSkin', …)`.
   - **진행도 저장 localStorage 키와 겹치지 않게** 별도 키(`axRoomSkin`) 사용.
5. **배경 캔버스(별/성운)를 스킨 인식하게** 한다:
   - `paper`: 어두운 성운/별 끄기(또는 아주 옅은 밝은 질감). 밝은 배경 위에 어두운 성운이 떠서 지저분해지면 안 됨.
   - `pixel`: 성운 끄고, 원하면 도트 별 몇 개만.
   - `blueprint`: 성운 대신 그리드(아래 참조)가 배경 역할.
   - `neon`: 현재대로 유지.
6. 폰트 로드("폰트" 섹션)를 `index.html` `<head>`에 추가.
7. 로컬 서버로 4개 스킨을 **시작화면 + 실제 슬라이드(7강)** 양쪽에서 확인.

## 스킨 팔레트

> 변수명은 예시다. **`style.css`의 실제 변수명에 매핑**할 것(임의 신규 남발 금지).
> `--accent-1~4`는 4개 상자 정체성 색(①왜 ②도구 ③적용 ④지속). 스킨마다 톤만 조정, 역할은 유지.

### paper — 미니멀 라이트 (기본)

```
--bg:            #F6F5F1   /* 따뜻한 오프화이트 */
--surface:       #FFFFFF   /* 카드: 흰색 + 옅은 그림자 (blur/glass 아님) */
--surface-border:#E4E1D9
--text:          #1B1B1A
--text-muted:    #6A6862
--accent-1:      #0E7490   /* 왜: 청록 */
--accent-2:      #6D28D9   /* 도구: 보라 */
--accent-3:      #BE185D   /* 적용: 마젠타 */
--accent-4:      #047857   /* 지속: 그린 */
--glow:          none
--radius:        14px
--shadow:        0 2px 10px rgba(0,0,0,.06)
--font-display:  'Pretendard', system-ui, sans-serif
--font-body:     'Pretendard', system-ui, sans-serif
질감/오버레이:   없음. 깔끔한 여백 위주.
주의: 네온에서 쓰던 glow/backdrop-blur/발광 그림자를 여기선 전부 제거.
```

### neon — 다크 네온 (현재 유지)

```
현재 style.css 값을 그대로 이 블록으로 이전. 참고용 기준값:
--bg:            #0A0A0F
--surface:       rgba(255,255,255,.06)  /* backdrop-blur 유지 */
--surface-border:rgba(255,255,255,.12)
--text:          #F4F4F8
--text-muted:    #9CA3B4
--accent-1:      #22D3EE
--accent-2:      #A855F7
--accent-3:      #F472B6
--accent-4:      #34D399
--glow:          0 0 24px   /* accent 색과 함께 */
--radius:        16px
--font-*:        현재 폰트 유지
오버레이:        기존 별/성운 캔버스 유지.
```

### pixel — 레트로 8비트 터미널

```
--bg:            #0C0F0A
--surface:       #111710   /* 평면, blur/그림자 없음 */
--surface-border:#2A5E33   /* 두꺼운 각진 테두리(2~3px) */
--text:          #C7FFB0
--text-muted:    #4E8C5A
--accent-1:      #33FF66   /* 왜: 형광 그린 */
--accent-2:      #FFB000   /* 도구: 앰버 */
--accent-3:      #FF5C7A   /* 적용: 픽셀 핑크 */
--accent-4:      #58E36B   /* 지속: 라임 */
--glow:          none      /* 대신 텍스트에 미세 phosphor: text-shadow 0 0 2px currentColor */
--radius:        0
--font-display:  'Galmuri11','Press Start 2P',monospace
--font-body:     'Galmuri11',monospace
오버레이(CRT 스캔라인): body::after {
  content:''; position:fixed; inset:0; pointer-events:none; z-index:9999;
  background:repeating-linear-gradient(rgba(0,0,0,.28) 0 1px, transparent 1px 3px);
}
버튼: 각진 형태 + 앞에 ">" 프롬프트 느낌. border-radius 0. 그라데이션/블러 금지.
```

### blueprint — 설계도

```
--bg:            #0A1A2F
--surface:       rgba(125,211,252,.05)   /* 반투명, 채움 최소 */
--surface-border:rgba(125,211,252,.35)   /* 얇은 1px 시안 라인 */
--text:          #DCEEFF
--text-muted:    #7FA6C8
--accent-1:      #7DD3FC   /* 왜 */
--accent-2:      #C4B5FD   /* 도구 */
--accent-3:      #FDA4AF   /* 적용 */
--accent-4:      #6EE7B7   /* 지속 */
--glow:          none
--radius:        2px
--font-display:  'IBM Plex Sans KR','Space Grotesk',sans-serif
--font-body:     'IBM Plex Sans KR',system-ui,sans-serif
오버레이(제도 그리드): body::before {
  content:''; position:fixed; inset:0; pointer-events:none; z-index:0;
  background:
    repeating-linear-gradient(0deg, rgba(125,211,252,.06) 0 1px, transparent 1px 32px),
    repeating-linear-gradient(90deg, rgba(125,211,252,.06) 0 1px, transparent 1px 32px);
}
카드: 채우기 최소 + 얇은 시안 외곽선. 원하면 모서리에 짧은 crosshair(+) 틱.
```

## 스킨 선택기 UI 사양

- 위치: **시작화면(시작 씬)** — "강의실 입장" 버튼 근처(위나 아래).
- 형태: 4개 옵션 가로 배열. 각 옵션 = 작은 색 스와치 + 라벨.
  - `페이퍼` (스와치 #6D28D9 위 밝은 카드 느낌) · `네온` · `픽셀` · `블루프린트`
- 라벨 표기: `페이퍼 · 네온 · 픽셀 · 블루프린트`
- 클릭 즉시 전체 페이지에 반영(라이브 프리뷰) + 현재 선택 표시(테두리/체크).
- 접근성: 버튼 요소로, aria-pressed 토글.
- **선택기 자체 스타일도 각 스킨에서 자연스럽게 보이도록** 변수 기반으로.

<!-- 픽셀: Galmuri(한글 픽셀) + Press Start 2P(라틴) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/projectnoonnu/[email protected]/Galmuri11.css">
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Press+Start+2P&display=swap">
<!-- 블루프린트 -->
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+KR:wght@400;600&family=Space+Grotesk:wght@500;700&display=swap">

> CDN 경로가 틀리면 CC가 올바른 최신 경로로 교체할 것.
