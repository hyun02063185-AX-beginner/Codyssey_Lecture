# CC 작업 지시서 — 7·8강 범용판 (15분 규격) 교체

> 위치: `Last_Lecture/order/7_8강_범용판_지시서.md` · 경로는 프로젝트 루트 기준.
> 전제: variant 구조 완료(ab8405b). **기본 `slides`만 교체**하고 `slidesPersonal`(경험판)은 절대 건드리지 않는다.
> 목표: 강사 진행 **15분+** 규격(각 16~17장). 개인 경험담 → 범용 사례로 치환, 이론 심화, 도식 3종 신규.

---

## 작업 순서

1. `js/data.js`에서 7·8강 구조 확인. **slidesPersonal 무변경 재확인.**
2. 아래 도식 SVG 3종을 기존 도식 8종과 같은 톤(사유의 방 다크·별빛골드·시안 라인)으로 제작해 `assets/`에 추가(파일명 아래 명시). 기존 image 슬라이드 스키마(title·src·caption) 사용.
3. 7강·8강의 기본 `slides`를 아래 배열로 교체(필드명은 data.js 실제 스키마 매핑).
4. 검증: 기본 URL에서 범용판 렌더(17장/17장), `?variant=personal`에서 경험판 그대로(14/16장 + P 뱃지), 이어보기 인덱스 범위 방어 동작, 콘솔 0건.
5. main 커밋.

---

## 신규 도식 3종 (SVG, assets/)

**D1 `assets/diagram-rag-flow.svg` — 지식검색 작동 흐름 (7강용)**
좌→우 4단계 흐름도: [질문] → [자료창고에서 뜻이 가까운 조각 찾기(돋보기+문서 아이콘)] → [찾은 조각을 근거로(문서 3장 하이라이트)] → [답변 생성]. 아래 보조 문구: "근거를 먼저 찾고, 그다음 답을 만든다". 화살표는 시안, 강조는 골드.

**D2 `assets/diagram-meaning-map.svg` — '뜻의 지도' (7강용)**
어두운 좌표평면 위에 단어 점들이 뜻별로 군집: 한 군집에 [출산·육아휴직·모성보호](서로 가깝게, 골드), 멀리 다른 군집에 [연차·반차], 또 멀리 [출장·경비]. 질문 별표(★"출산 규정?")가 첫 군집 근처에 찍혀 가까운 점들과 점선으로 연결. 보조 문구: "글자가 아니라 거리(뜻)로 찾는다".

**D3 `assets/diagram-agent-loop.svg` — 에이전트 루프 (8강용)**
원형 순환: [목표] → [관찰(보기)] → [판단(생각)] → [행동(도구 실행)] → 다시 [관찰]로 화살표 순환. 루프 바깥에 [사람 확인 🙋] 게이트가 [행동] 직전에 끼어드는 분기 표시. 보조 문구: "본 것으로 다음을 정한다 — 위험한 행동 앞엔 사람 확인".
