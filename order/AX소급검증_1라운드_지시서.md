## 배경 (첫걸음 검증과 무엇이 다른가)

에이전트 5종은 첫걸음(AI_First_Step)에서 실전 검증됐으나, **본진 콘텐츠에는 한 번도 적용된 적 없다.** 조건 차이를 인지하고 감사할 것:

| | 첫걸음 | AX (이번) |
|---|---|---|
| 대상 독자 | 주니어·사무직 입문자 | **비개발 실무 재직자**(마케팅·기획·운영) |
| 화자 | 김주임(신입 성장 서사) | **화자 서사 없음** — 범용 사례 중심 |
| 규격 | 12~14장 | **13~17장**(15분 규격) |
| 도식 | E 시리즈 라이트 | **D 시리즈 다크**(사유의 방 톤) |
| 특수 구조 | 없음 | **7·8강 slidesPersonal**(경험판 variant) |
| 작성 시점 | 최근·연속 | **상자별로 나눠 작성** → 상자 간 편차 가능성 |

- 헌법은 `docs/톤앤매너.md`의 **AX판**을 적용한다(첫걸음판 기준으로 재단하지 말 것).
- 최근 개정된 3개 조항(오해 셋 대체 장치 예외 · **캡스톤 강 예외** · 의미색 예외)이 AX에도 적용됨을 유의. 캡스톤 예외는 20강 대상이므로 이번 라운드(상자1)에서는 해당 없음.
- `docs/콘텐츠_현황.md`(AX판)에서 완료 상태 확인 후 감사 대상 확정.

## 감사 실행 (상자1 = 01~05강)

### 1) persona-reviewer

- **관점 지정**: "AI를 거의 안 써본 **비개발 실무 재직자**(예: 마케팅 5년차, 엑셀은 쓰지만 개발은 모름)"
- 중점 항목:
  ① **용어 노출** — 설명 없이 등장한 용어·영문 약어 (상자1은 입문 구간이라 특히 중요)
  ② **사례 현실성** — 범용 사례가 실무자에게 "내 얘기 같은가", 지어낸 티가 나는 곳
  ③ **과제 실행 가능성** — 재직자가 오늘 실제로 할 수 있는가
  ④ **난이도 곡선** — 01→05강이 급격히 어려워지는 지점
- 첫걸음과 달리 **화자 서사 검증은 해당 없음**(범용 사례 구조).

### 2) tone-keeper

- 헌법 **AX판** 대조. 중점:
  ① 규격 요소(사례·오해 셋·생각해보기·한 장 정리+과제) 누락·편차
  ② **상자 내 일관성** — 같은 요소가 강마다 다르게 처리된 곳(형식·분량·명칭)
  ③ 어투 일탈(실무자 대상 톤에서 벗어난 곳)
  ④ 도식 D 시리즈 톤·팔레트 준수
  ⑤ 관통 문장("사람이 방향, AI가 초안") 사용의 적절성

### 3) qa-runner

- 상자1 렌더 전수(01~05강 전 슬라이드), 도식 D4~D7 로드·확대, 티저 체인 01→02→…→06, 5스킨, 375px, 이어보기, 핵심훑기, 콘솔 0건.
- `npm test`(86개) 통과 확인.

### 4) boundary-keeper

- 이번 라운드는 코드 변경이 없으므로 **경계 감사 대신**: 상자1 관련 자산(도식 파일·data.js 구조)이 엔진_경계.md 분류와 일치하는지 확인 + 규범 문서 동기화 상태(첫걸음과 비교) 점검.
