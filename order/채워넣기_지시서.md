## 목표

`Last_Lecture` 강의 페이지의 **데모 2강** 슬라이드를 실제 내용으로 채운다.

- **7강 = 지식검색 (RAG)** — 총 14장
- **8강 = AI 에이전트 입문** — 총 16장

이 문서 아래 "슬라이드 내용" 섹션의 데이터를 각 강의 `slides` 배열에 넣는다.

---

## 작업 순서 (반드시 이 순서로)

1. **먼저 `js/data.js`를 읽어라.** 다음을 파악한다.
   - lecture(강의) 객체가 배열인지 객체인지, 7강·8강을 어떻게 식별하는지(id, index 등)
   - 슬라이드 객체의 **실제 필드명** (예: `subtitle`인지 `sub`인지, `items`인지 `list`인지 등)
   - 이미 들어있는 데모 샘플 슬라이드의 정확한 형식
2. 아래 "슬라이드 내용"의 7강 14장 · 8강 16장을 **data.js의 실제 필드명에 맞게 변환**해서 각 강의 `slides` 배열에 넣는다. 기존 데모 샘플은 교체한다.
3. **7·8강 외 다른 강의, `css/`, `js/`의 엔진 파일(room.js, slides.js, main.js 등)은 절대 건드리지 않는다.** 오직 `js/data.js`의 7·8강 slides만 수정.
4. 완료 후 `python -m http.server 8000`으로 띄워, 두 강의가 정상 렌더되고 JS 콘솔 오류가 없는지 확인한다.

### ⚠️ 주의

- 이 문서의 슬라이드 데이터는 **인수인계 스키마 기준 초안**이라 필드명이 실제 `data.js`와 다를 수 있다. **임의로 새 필드를 만들지 말고, 반드시 data.js의 실제 필드명으로 매핑**할 것.
- 슬라이드 타입: `cover` · `big` · `bullets` · `quote` · `split` · `closing`.
- `split`의 `left` / `right` 배열은 **첫 항목이 컬럼 제목**, 나머지가 본문 줄이다.
- `title` / `word` / `text` 안의 `\n`은 줄바꿈이다.

## 톤 원칙 (내용 손볼 때 유지)

- 전문용어 최소화 — "RAG"는 화면상 **"지식검색"**으로 노출(괄호로 RAG 병기).
- 대형 키워드 슬라이드 위주, 유머/패러디 허용.
- 각 강의는 다음 강의 티저로 마무리.
- 개인 스택 표기: NanoClaw(게이트웨이/두뇌) · n8n(자동화) · Dify(지식검색).
